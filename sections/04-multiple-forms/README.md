# 第4章 1つの画面に複数のフォームを並べる

ここまでは1つのフォームを育ててきました。この章では、同じ `index.html` の中に
行き先も項目も違うフォームを並べ、3種類の検索URLを作れるページに仕上げます。

| 見出し | 行き先 | パラメータ |
|---|---|---|
| 1. 資料検索 | `docs.html` | `dept` / `title` / `author` / `date` |
| 2. 全文検索 | `fulltext.html` | `dept` / `word1` / `word2` / `word3` |
| 3. 棚検索 | `shelf.html` | `room` / `cabinet` / `drawer` |

この章の方針は **まとめないこと** です。3つの処理はよく似ていますが、1つの関数に
共通化しません。上から順に読めば全部わかる状態を保ち、1つを直したときに別のフォームが
壊れる心配をなくします。まとめ方の話は最後のコラムで触れるだけにします。
