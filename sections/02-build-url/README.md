# 第2章 文字列結合でURLを作る

入力した値を使って検索用の URL を組み立て、クリックして開けるようにします。
使うのは文字列の足し算（`+`）だけです。

この章では、わざと素朴な書き方で進めます。項目が増えると「`?` と `&` のどちらを足すか」を
自分で判断することになり、記号や日本語を入れると URL が壊れます。
その面倒を一度体験しておくと、第3章で道具に置き換える意味がはっきりします。

受け取り側のページ（`docs.html`）は `example/` に同梱してあります。
検索システムの代わりに、受け取ったパラメータを表に並べるだけのページです。
