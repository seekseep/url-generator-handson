# 開発ツール（サクラエディタ / Edge）

このハンズオンで使うのは、エディタとブラウザの 2 つだけです。
Node.js やパッケージマネージャのインストールは要りません。

## サクラエディタ

HTML ファイルの編集に使います。[公式サイト](https://sakura-editor.github.io/) から
インストールしてください。

### 新しいファイルを作る

1. サクラエディタを開く
2. 何か書いてから **ファイル → 名前を付けて保存**
3. ファイル名を `index.html` にする
4. **文字コードセット** を `UTF-8`、**改行コード** は `CRLF` のままでよい

> **拡張子に注意**
> 保存ダイアログの「ファイルの種類」が「テキストファイル (*.txt)」になっていると、
> `index.html.txt` という名前で保存されてしまいます。
> ファイル名を入力する欄に `index.html` と書いたうえで、種類を「すべてのファイル」にしてください。

### 文字コードを確認する

画面の下に現在の文字コードが出ています。`SJIS` になっていると、ブラウザで開いたときに
日本語が文字化けします。**ファイル → 文字コードセット指定 → UTF-8** で変換してから保存し直してください。

HTML の `<head>` に `<meta charset="utf-8" />` が入っているので、ファイル側も UTF-8 でそろえます。

### 色分けを有効にする

`.html` で保存すると HTML の色分けが効きます。効いていない場合は
**設定 → タイプ別設定一覧** から HTML を選んでください。タグと文字が見分けられるだけで、
書き間違いにかなり気づきやすくなります。

## Microsoft Edge

作ったページの表示確認に使います。Windows なら最初から入っています。

### ファイルを開く

エクスプローラーで `index.html` をダブルクリックすると Edge で開きます。
アドレスバーには `file:///C:/...` のような表示になります。

このハンズオンは画像や音を読み込まないので、この開き方で全部動きます。
簡易サーバーを立てる必要はありません。

### 書き換えたら再読み込み

サクラエディタで保存しても、ブラウザの表示は自動では変わりません。
**保存 → Edge に切り替え → `F5`（再読み込み）** が基本の往復です。

変更したはずなのに変わらないときは `Ctrl + F5`（キャッシュを無視して再読み込み）を試してください。

### 開発者ツール（DevTools）

`F12` で開きます。このハンズオンで使うのは主に 2 つのタブです。

- **Console** — `console.log` で出した値や、JavaScript のエラーが出ます。
  赤い文字が出ていたら、そこに書き間違いの手がかりがあります
- **要素（Elements）** — いま画面に出ている HTML を見られます。
  `id` が思ったとおりに付いているか確認するときに使います

うまく動かないときは、まず Console を開いてエラーが出ていないか見てください。
